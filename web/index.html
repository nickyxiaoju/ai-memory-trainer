把任何一段文字，变成会挖空的默写训练

拍照取文、AI 挑关键词挖空、逐空实时判定、中途闯关出题，一条流水线跑完；学生用它背课本，长辈用它练脑力。

未登录时全程在这台浏览器内完成，不产生任何服务器数据；登录后只有练习统计与关键词明细会同步到你自己的 Supabase 账号。文本与密钥只发往官方推理接口（Hugging Face / Groq），本站没有服务端密钥。

输入

拍照即可练（OCR）

课本、讲义、手写卡片拍一张照，就能变成练习内容。

图片交给 Hugging Face 视觉模型识别成文字并自动填入内容框，识别结果可再手工校正；也可以直接粘贴长文本。没有 Token 时，示例文本与演示模式照样能跑完整流程，输入不再是门槛。

提取

AI 智能挖空

大模型替每一段挑出人名、地名、关键数据，把它们换成空格。

背诵从「照着抄一遍」变成「凭记忆把关键词提取出来」，这正是记忆科学里最有效的那一步。没有配置 Groq Key 时自动改用本地关键词算法，练习照常进行，只是挑词没有大模型那么懂语义。

反馈

逐空实时判定

原文照常显示，只在关键词处填词：写对转绿，写错转红，红色可以接着改。

每个空独立判定，进度实时可见；本段关键词全部写对才进入下一段。Tab 按行文顺序在空之间移动，Enter 直接定位到第一个还没写对的位置，键盘就能走完整个默写流程。

校验

阶段性闯关测验

练到一半自动停下来，出一道只用已练内容出的题。

答对才解锁后续段落，形成「提取 — 校验 — 继续」的闭环，避免「一路抄到底却什么都没记住」。题目优先由 AI 现场生成，接口不可用时退回本地出题；不想被拦下，也可以在练习设置里关掉这一项。

可用

适老化与无障碍

字更大、可读、可听，键盘能完成全部操作。

大字模式、慢速朗读、高对比的红绿反馈、屏幕阅读器标签与实时播报都在流程之内；分屏导航的圆点是可聚焦的按钮，当前屏用拉长的胶囊形状区分，而不是只靠颜色，色觉障碍的用户也看得出位置。

复盘

练习报告

结束时给出用时、正确率、提示次数与闯关结果。

报告按本次实际练过的内容统计，学生便于复盘，家属也能看长辈今天练了多少、卡在哪里。登录之后，历次记录会出现在个人中心，可以回看逐空明细、改标题或删除。

补充

技术路线与为什么值得做

展开看流水线与项目动机
图片 / 长文本→ Hugging Face Inference（OCR）→ 分段引擎→ Groq（关键词挖空）→ 逐空比对默写→ Groq（50% 闯关出题）→ 学习报告

为什么值得做：背诵类练习工具普遍停留在「复制—粘贴—对答案」，没有真正的记忆提取； 而市面上的老年认知训练 App 多为付费游戏化题目，缺少「用自家课本、自家内容来练」的能力。 本项目用两个免费推理接口拼出一条通用流水线：任何一段文字（或一张照片）都能立刻变成一套有 AI 挖空、有闯关校验的默写训练， 城乡学生与老年用户都可零成本使用。

数据与隐私：密码只经过 Supabase Auth，不进数据表、不进本机存储、不出现在日志里； 前端只使用 anon 公钥，能读到哪些行完全由数据库的行级安全策略决定，账号之间互不可见。
